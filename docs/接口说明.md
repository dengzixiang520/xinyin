# SONOTRACE 比赛展示端 · 接口说明

后端：FastAPI，默认端口 `8077`（本机开发）／`8000`（`run.sh`/`run.bat`）。
交互式文档：`http://127.0.0.1:8077/docs`。

**所有指标均来自 `results/` 下的论文真实训练产物**，代码里没有任何硬编码的
准确率、曲线或阈值。取不到的字段一律返回 `null`，前端显示 `TBD`。

## 目录

| 分组 | 接口 |
|---|---|
| 健康与版本 | `GET /api/health`、`GET /api/version` |
| 模型 | `GET /api/models`、`GET /api/checkpoints` |
| 论文实验 | `GET /api/overview`、`GET /api/experiments`、`GET /api/experiments/{name}` |
| 分阶段结果 | `GET /api/sqa`、`GET /api/seg`、`GET /api/datasets` |
| 消融与审计 | `GET /api/ablation`、`GET /api/audit` |
| 风险-覆盖率 | `GET /api/selective`、`GET /api/selective/experiments`、`GET /api/selective/{name}`、`GET /api/gate` |
| 推理 | `POST /api/analyze`、`POST /api/analyze_sample`、`POST /api/analyze_batch`、`POST /api/quality_check` |
| 多模型对比 | `POST /api/compare`、`POST /api/compare_sample` |
| 样本音频 | `GET /api/samples`、`GET /api/sample_audio/{name}` |
| 历史与复核 | `GET /api/history`、`GET /api/history/{id}`、`GET /api/review-queue`、`POST /api/review-queue/{id}`、`GET /api/stats`、`POST /api/maintenance/prune` |

## 一、健康与版本

### `GET /api/health`
```json
{
  "status": "ok", "version": "3.1", "uptime_sec": 512.3,
  "engine_mode": "real_pytorch_model",
  "device": "cpu",
  "weights": { "cls": {"loaded": true, "mb": 87.64},
               "seg": {"loaded": true, "mb": 7.13},
               "sqa": {"loaded": true, "mb": 3.3} },
  "cls": { "ready": true, "model": "dg_resnet_cbam", "params_M": 22.932,
           "use_cwt": true, "use_cbam": true, "use_mixstyle": true, "use_grl": true },
  "seg": {"ready": true}, "sqa": {"ready": true},
  "n_checkpoints": 4
}
```
`engine_mode` 为 `dsp_acoustic_fallback` 表示分类权重缺失，系统仍可用（仅输出 DSP 声学特征）。

### `GET /api/version`
Python / NumPy / Torch 版本、CUDA 可用性、GPU 名称、进程运行时长。

## 二、模型

### `GET /api/checkpoints`
多模型对比池。`available` 只表示权重文件在盘上；`loaded` 表示已进内存（惰性加载）。
```json
{ "default": "proposed",
  "n_available": 4,
  "items": {
    "proposed": {"label": "Proposed Full", "table": "Table3", "available": true, "loaded": true},
    "naive":    {"label": "普通混训 CNN",  "table": "Table3", "available": true, "loaded": false},
    "lodo":     {"label": "LODO 域泛化",   "table": "Table2", "available": true, "loaded": false},
    "nocwt":    {"label": "去 CWT 双视图", "table": "Table4", "available": true, "loaded": false}
  } }
```
四个检查点均为论文真实训练产物，`backend/config.py::COMPARE_CHECKPOINTS` 可增删。

## 三、论文实验

### `GET /api/overview`
首页聚合：`sqa`（5 折 AUC / F1 / 零样本 AUC）、`seg`（最佳事件 F1、最终帧准确率）、
`experiments`（完成数 / 总数 / headline）、`dataset`（记录数 / 小时 / 受试者 / 库数）、
`gate`（当前门控）、`review`（复核统计）。

### `GET /api/experiments`
```json
{ "available": true, "total": 12, "completed": 10,
  "headline": { "proposed_macc": 0.6641, "baseline_macc": 0.6141,
                "gain_over_naive": 0.05, "gain_lodo": -0.0006 },
  "items": [ { "name": "cross_proposed_full", "table": "Table3",
               "available": true,
               "metrics": { "macc_uar": 0.6641, "auroc": 0.7197, "sensitivity": 0.5389,
                            "specificity": 0.7893, "macro_f1": 0.6643, "ece": 0.0893,
                            "params_M": 22.932, "latency_ms_5s_clip": 6.5,
                            "selective_abstention": {"reject_10pct_macc": 0.6775,
                                                     "reject_20pct_macc": 0.705},
                            "confusion_matrix": [[547,146],[261,305]] },
               "config": { "protocol": "cross_dataset", "model": "dg_resnet_cbam" },
               "curve": [ {"epoch": 3, "macc": 0.55, "auroc": 0.60}, … ] } ] }
```
未完成实验 `available:false`，`metrics`/`curve` 为空。混淆矩阵顺序 `[[TN,FP],[FN,TP]]`。

### `GET /api/experiments/{name}`
单个实验对象；未知实验返回 404。

### `GET /api/sqa` · `GET /api/seg` · `GET /api/datasets`
Stage 1 质控标定、Stage 2 分割训练曲线、Table 1 数据集统计。

## 四、消融与审计

### `GET /api/ablation`
```json
{ "available": true, "n_done": 4, "n_total": 5,
  "baseline": { "macc_uar": 0.6641, "auroc": 0.7197 },
  "rows": [ { "mechanism": "CWT 双视图", "macc_uar": 0.6005,
              "delta_macc": 0.0636, "delta_auroc": 0.0757, "available": true } ],
  "most_important": "CWT 双视图" }
```
`delta = 完整模型 − 消融项`；正值表示该机制有贡献。

### `GET /api/audit`
数据血缘 + **可复现**检查。检查项全部由 `master_pcg_manifest.csv` 与
`data_audit_report.json` 在本地算出，不依赖服务器文件系统：

- 音频文件可解码性（服务器端全量扫描，损坏 0 个）
- 外测集受试者隔离（ZCHSound 受试者与训练集交集必须为 0）
- 受试者级折内唯一（剔除 `fold_internal = -1` 未分配折哨兵后统计）
- 声学标签完整性 / 时长有效性 / 路径完整性

## 五、风险-覆盖率（本系统核心机制）

### `GET /api/gate`
```json
{ "current": { "mode": "standard", "uncertainty_threshold": 0.3467,
               "margin_threshold": 0.1, "calibrated": true,
               "calibrated_on": "cross_proposed_full 零样本外测集 (n=1259)" },
  "modes": [ {"mode":"loose","label":"宽松","uncertainty_threshold":0.3511,
              "margin_threshold":0.05,"coverage":0.8539,"metrics":{"macc":0.6904},
              "gain_macc":0.0263}, … ] }
```

### `GET /api/selective`
一次返回四块内容（`curves` / `calibration` / `domain` / `gate`）：

| 字段 | 含义 |
|---|---|
| `curves.curve_uncertainty` | 只按不确定度拒识的覆盖率-MAcc 折线 |
| `curves.curve_margin` | 只按决策边际拒识的折线 |
| `curves.operating_point` | 标准档实际落点 |
| `curves.modes` | 三档（宽松/标准/严格）的阈值与实测覆盖率、MAcc、ΔMAcc |
| `calibration.reliability` | 可靠度图分箱（平均置信度 vs 经验准确率） |
| `calibration.ece` | 期望校准误差 |
| `domain.domains` | 按设备/站点域的分解（含开/关拒识两套指标） |

**口径核对**：在 `cross_proposed_full` 上重算得到 coverage 90% → MAcc 0.6775、
coverage 80% → MAcc 0.7050，与论文 `metrics.json` 的
`selective_abstention.reject_10pct_macc` / `reject_20pct_macc` **逐位一致**，
说明本模块与论文的拒识实现同口径。

## 六、推理

### `POST /api/analyze`
`multipart/form-data`，字段 `file`。查询参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `gradcam` | `true` | 是否计算 Grad-CAM（关闭可省 ~30% 耗时） |
| `checkpoint` | `proposed` | 用哪个检查点推理 |
| `gate_mode` | `standard` | `loose` / `standard` / `strict` |

响应顶层：`filename` `checkpoint` `engine_mode` `duration_sec` `sample_rate`
`quality` `visualization` `segmentation` `prediction` `gradcam` `analysis_id`

`prediction` 关键字段：
```json
{ "verdict_key": "pending",        // normal | abnormal | pending
  "label": "不确定 · 建议人工复核",
  "gate_hit": "margin",           // none | uncertainty | margin | quality | no_model
  "abstain_threshold": 0.3467, "margin_threshold": 0.1, "gate_mode": "standard",
  "gate_calibrated_on": "cross_proposed_full 零样本外测集 (n=1259)",
  "abstained": true,
  "prob_abnormal": 0.4006, "prob_normal": 0.5994,
  "uncertainty": 0.3445, "mc_passes": 11, "mc_samples": [...] }
```

**判定顺序**：质控未过 → 不确定度 ≥ 阈值 → 决策边际 < margin → 才给二分类结论。
MC-Dropout 采样**固定随机种子**（`_MC_SEED`），同一条音频任意次调用结果完全一致。

### `POST /api/analyze_sample`
同上，但用 `?name=` 指定 `samples/` 里的文件名（无需上传）。

### `POST /api/analyze_batch`
`multipart`，字段 `files`（可多个，**上限 12**）。查询参数同 `analyze`（`gradcam` 默认 `false`）。
逐条容错：单个文件失败不影响其余，失败项进 `errors[]`。
```json
{ "n_total": 6, "n_ok": 6, "n_error": 0, "elapsed_sec": 2.34,
  "summary": {"abnormal": 1, "normal": 4, "pending": 1, "abstain_rate": 0.1667},
  "items": [ {"filename": "13918_AV.wav", "prob_abnormal": 0.4006,
              "uncertainty": 0.3445, "verdict_key": "pending",
              "gate_hit": "margin", "analysis_id": 26} ],
  "errors": [] }
```

### `POST /api/quality_check`
只跑六维质控（给 ESP32 等硬件端做采集前拦截），不加载分类模型。

## 七、多模型对比

### `POST /api/compare_sample` · `POST /api/compare`
同一段录音在多个检查点上并排推理。`compare_sample` 用 `?name=`；
`compare` 用 `multipart file`。两者都可用 `?checkpoints=proposed,naive` 限定子集。
```json
{ "filename": "13918_AV.wav", "quality_passed": true,
  "all_agree": false,
  "models": [ {"checkpoint":"proposed","label":"Proposed Full",
               "prob_abnormal":0.4006,"uncertainty":0.3445,
               "verdict_key":"pending","gate_hit":"margin",
               "params_M":22.932,"use_cwt":true,"use_cbam":true,
               "use_mixstyle":true,"use_grl":true}, … ] }
```
> 说明：门控阈值是在 `proposed` 的概率分布上标定的，套用到其它检查点时
> 阈值并非各自的等覆盖率点，仅用于横向参考。

## 八、历史与复核

分析结果自动落库（SQLite，`data/sonotrace.db`）。`verdict_key = pending` 的记录
**自动**生成一条待复核工单。

| 接口 | 说明 |
|---|---|
| `GET /api/history?limit&offset&verdict_key` | 分析历史，不含完整 payload |
| `GET /api/history/{id}` | 单条详情，`payload` 为完整分析结果 |
| `GET /api/review-queue?status=open&limit&offset` | 待复核队列（join 出文件名/概率/不确定度） |
| `POST /api/review-queue/{id}` | JSON body `{"status":"confirmed"\|"rejected"\|"escalated","reviewer":"web","note":""}` |
| `GET /api/stats` | 总分析数 / 待复核数 / 各判定计数 / 平均不确定度 / 拒识率 |
| `POST /api/maintenance/prune?keep_days=30` | 清理旧记录（复核工单级联删除） |

## 九、约定与限制

1. **不伪造数据**：任何取不到的指标返回 `null`，前端显示 `TBD`。
2. **零翻车优先**：权重缺失自动降级为 DSP 模式；数据库异常只写日志、不影响分析返回。
3. **可复现**：MC-Dropout 固定种子；阈值由数据反解而非手写常数。
4. **不做路径穿越**：`sample_audio`、`analyze_sample`、`selective` 均对文件名做 `os.path.basename`。
5. **临床合规**：所有结论附「辅助参考，不替代专业医师诊断」声明；拒识即提示送人工复核。
6. 未实现：鉴权（比赛演示环境）、异步任务队列（批量已限制 12 个同步处理）、音频格式白名单仅按扩展名。
